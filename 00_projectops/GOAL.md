# GOAL

## 한 문장

디자인을 못 하는 오프라인 MC가 **2분 안에** 고객에게 보낼 카카오톡 배너를
만들어 다운로드하고, 만든 배너를 보관함에서 재사용할 수 있게 한다.

## 사용자

| 구분 | 설명 |
|---|---|
| 주 사용자 | SK매직 상품 오프라인 MC. 디자인 툴 사용 경험 없음. 현장에서 **폰**으로 작업 |
| 보조 사용자 | 팀장 — 팀원 프리셋 관리, 일괄 생성 |
| 최종 수신자 | 고객 — 카카오톡 개인 채팅방 또는 채널 메시지로 배너를 받는다 |

## 성공 기준 (측정 가능)

| 지표 | 목표 |
|---|---|
| 첫 배너까지 걸리는 시간 | 신규 MC 기준 **2분 이내** |
| MC가 만지는 화면 수 | **4단계** (+ 보관함) |
| QA 게이트 통과율 | 노출 시안 **100%** (실패분은 애초에 노출 안 함) |
| 재사용률 | 보관함에서 재발송·재다운로드 **30% 이상** |
| 컴플라이언스 사고 | **0건** (금지 표현·고지 누락) |

## 만드는 것 (In scope)

- 상품 카탈로그 자동 수집 + 이미지 여백 트림
- 푸시 문구 3안 자동 생성 + 광고 표현 검수·치환
- 배너 스타일 6종 (완성 시안을 눈으로 보고 선택)
- 단품 배너 / 종합 배너(2~12종) 자동 배치
- 4규격 출력: 800×600 · 1080×1080 · 1080×1350 · 1080×1920
- 문구 겹침 회피 엔진 + 자동 QA 게이트 8항목
- 보관함 — 생성 이력, 즐겨찾기, 고객 태그, 재사용
- 동반 인사말 자동 작성 + 복사

## 만들지 않는 것 (Out of scope)

- **제품 사진 생성·합성** — 실물 왜곡은 표시광고법 리스크
- 카카오톡 자동 발송 API 연동 — 1차는 MC가 직접 붙여넣기
- 고객 관리(CRM) 기능 — 태그 수준까지만
- 배너 자유 편집기(드래그로 요소 이동) — 비전문가에게 위험
- SK매직 공식 CI 자산 제작 — 브랜드 담당 부서 영역

## 핵심 설계 원칙

1. **MC에게 판단을 요구하지 않는다.** 겹침·대비·글자수는 엔진이 보장하고,
   MC는 통과한 시안 중 마음에 드는 것만 고른다.
2. **내부 용어를 노출하지 않는다.** 슬롯·IoU·패턴코드·QA는 화면에 없다.
3. **숫자는 코드가 쓴다.** 가격·고지문은 LLM이 만들지 않는다.
4. **브랜드는 절제한다.** Neutral first, red with intent — 레드 면적 5% 이내.
