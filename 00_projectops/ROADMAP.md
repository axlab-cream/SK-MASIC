# ROADMAP

전체 6주. 각 Phase는 **완료 기준(DoD)** 을 통과해야 다음으로 넘어간다.

```
W1        W2        W3        W4        W5        W6
├─ P0 ────┼─ P1 ────┼─ P2 ────┼─ P3 ────┼─ P4 ────┼─ P5 ─┤
 골격·수집  렌더·단품  종합·스타일 LLM·QA    UI·보관함  KMS·운영
```

---

## P0 · 골격 · 카탈로그 (W1)

**목표** 배너를 만들 재료를 신뢰할 수 있게 확보한다.

DoD
- [ ] 상품 20종 이상이 `products.json` 에 스키마 검증 통과 상태로 존재
- [ ] 모든 상품에 여백 트림된 이미지가 1장 이상 존재
- [ ] 약정별 가격이 배열로 저장되고, 없는 값은 `null` (추정값 0건)
- [ ] `syncedAt` 이 기록되고 7일 초과 감지가 동작
- [ ] 엑셀 오버라이드로 가격 1건을 덮어쓰는 시나리오 통과

리스크 — 공식몰 DOM 구조 변경. 셀렉터를 설정 파일로 분리해 코드 수정 없이 교체 가능하게 한다.

## P1 · 렌더 엔진 · 단품 (W2)

**목표** 한 제품으로 실제 PNG가 나온다.

DoD
- [ ] `tokens.css` 가 SK guide 값과 1:1 일치 (컬러·타입·자간·라디우스)
- [ ] 0~1 슬롯 정의 하나로 800×600 과 1080×1350 이 모두 렌더
- [ ] 단품 패턴 S1~S4 전부 동작
- [ ] `document.fonts.ready` 대기 후 캡처 — 폴백 폰트로 찍힌 사례 0건
- [ ] 요소별 실측 rect 가 JSON 으로 반환
- [ ] 샘플 PNG 8장(4패턴×2규격)이 육안 검수 통과

## P2 · 종합 배너 · 스타일 6종 (W3)

**목표** 제품 2~12종, 스타일 6종, 규격 4종의 조합이 전부 나온다.

DoD
- [ ] 제품 수 × 규격 결정 표대로 패턴이 자동 선택
- [ ] 겹침 회피 6개 규칙이 순차 적용되고 로그가 남는다
- [ ] fit-text 가 최소 폰트 미달 시 줄 수 증가 → 재생성 요청 순으로 넘긴다
- [ ] 6스타일 × 4규격 = 24장 샘플이 전부 생성
- [ ] 레드 면적이 모든 스타일에서 5% 이내 (자동 측정)
- [ ] 검정 배경 스타일에서 CTA 대비 4.5:1 이상

## P3 · OpenAI 통합 · QA 게이트 (W4)

**목표** 문구가 자동으로 나오고, 나쁜 결과가 MC에게 도달하지 않는다.

DoD
- [ ] 문구 3안이 Structured Outputs 로 반환
- [ ] 응답에 가격·고지문 필드가 있으면 전체 폐기가 동작 (의도적 오류 주입 테스트)
- [ ] 글자수 초과 시 상한을 낮춘 재요청이 최대 2회 안에 수렴
- [ ] 3속성 순서(관리→기능→색상) 정규식 검증 통과율 100%
- [ ] 금지어 20종 사전이 치환 또는 폐기로 처리
- [ ] QA 8항목 판정기가 실측 rect 기준으로 동작
- [ ] 실패 반송 정책이 무한 루프 없이 종료
- [ ] 스타일 목록 최소 3개 보장

## P4 · MC UI · 보관함 (W5)

**목표** MC가 혼자 2분 안에 배너를 받는다.

DoD
- [ ] 4단계 화면이 모바일(≤767px, 좌우 20px)에서 동작
- [ ] 3단계 진입 시 스타일 6종이 병렬 프리렌더되어 대기 3초 이내
- [ ] 통과하지 못한 시안이 목록에 나타나지 않음
- [ ] 4단계에서 사진 저장 / 카톡 전송이 실기기에서 동작
- [ ] 보관함에 세트 단위 저장, 재다운로드·재발송 동작
- [ ] 신규 MC 3명 대상 **첫 배너 2분 이내** 사용성 테스트 통과
- [ ] 태블릿 2-pane 대응

## P5 · KMS · 운영 (W6)

**목표** 쓸수록 빨라지고, 사고가 재발하지 않는다.

DoD
- [ ] 성공 조합·실패 원인·채택 문구가 `05_kms/` 에 자동 적재
- [ ] 스타일 목록 정렬이 과거 채택률을 반영
- [ ] 회귀 테스트 세트(6×4×5 = 120 케이스)가 CI 에서 통과
- [ ] 카탈로그 7일 초과 시 생성 차단이 실제로 막는다
- [ ] 시즌 테마 팩으로 월별 캠페인 컬러가 치환

## 마일스톤

| 시점 | 확인 가능한 것 |
|---|---|
| W1 말 | 상품 데이터가 신뢰할 수 있게 쌓였다 |
| W2 말 | 단품 배너 PNG 실물을 볼 수 있다 |
| W3 말 | 스타일 6종 × 4규격 24장을 한 화면에서 비교할 수 있다 |
| W4 말 | 문구까지 자동으로 붙은 배너가 나온다 |
| W5 말 | **MC가 직접 써서 고객에게 보낼 수 있다** ← 실사용 시작점 |
| W6 말 | 운영 안정화 + 회귀 방어 |

## 축소 시나리오 (일정 압박 시)

우선순위 낮은 순으로 잘라낸다.
1. P5-05 시즌 테마 팩 → 다음 분기
2. P4-09 일괄 생성 큐 → 팀장 요청 시
3. P4-08 태블릿 → 모바일만 우선
4. 스타일 6종 → **뉴트럴 화이트 + 혜택 강조 + 가격 강조 3종** (O-07)
5. 규격 4종 → **1080×1350 + 800×600 2종**

절대 자르지 않는 것 — QA 게이트(P3-06), 금지어 검수(P3-03), 가격 LLM 차단(P3-02).
이 셋은 컴플라이언스 사고와 직결된다.
