# 성공 조합 · PoC 매트릭스

QA 8항목 전량 통과. LLM 호출 0회 (규칙 엔진이 후보를 1개로 좁혔다).

## 규격 × 종횡비 → 선택된 패턴

| 규격 | 종횡비 | 단품 | 3종 | 6종 |
|---|---|---|---|---|
| 800×600 | 1.33 | S1 (밴드형은 S2) | C3 | — (최대 3종) |
| 1080×1080 | 1.00 | S2 | C3 | — (최대 4종) |
| 1080×1350 | 0.80 | S2 (밴드형은 S3) | C3 | C12 / C6 |
| 1080×1920 | 0.5625 | S2 / S3 | C3 | C12 / C6 |

## 스타일별 통과 특성

| 스타일 | 충돌 해소 | 스크림 | 용량(1350) | 비고 |
|---|---|---|---|---|
| 뉴트럴 화이트 | 0회 | 0 | 68–87KB | 가장 안정 |
| 혜택 강조 | 0회 | 0 | 68–88KB | 밴드가 대비를 보장 |
| 가격 강조 | 0–3회 | 0 | 80–96KB | 가로형에서 3회 발생 |
| 프리미엄 블랙 | 0회 | 0 | 138–156KB | 그라데이션 때문에 용량 최대 |
| 아이스 캠페인 | 0회 | 0 | 87–175KB | 밴드 그라데이션 |
| 카드 리스트 | 0회 | 0 | 89–190KB | 12종까지 통과 |

## 재사용 포인트

- 가격 강조 가로형(800×600)은 충돌 해소가 3회 발생한다 → 이 조합은 프리렌더 우선순위를 낮춘다
- 프리미엄 블랙은 용량이 2배다 → 500KB 상한에 여유가 적으므로 1920 규격에서 주의
- 카드 리스트는 행 높이 < 최소폰트×2.35 이면 속성 줄을 접는다. 9종 이상은 1920 규격 권장
