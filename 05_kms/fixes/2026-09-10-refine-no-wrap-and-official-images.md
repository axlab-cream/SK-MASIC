# 리파인 패턴 — 가격 줄바꿈·상품 대체 자산 수정

## 문제

- 4종 이상 종합 패턴에서 카드 폭이 줄어들어 가격이 두 줄로 떨어질 수 있었다.
- 제품 사진이 없을 때 코드로 만든 SVG 실루엣이 출력되는 경로가 남아 있었다.
- 3종 혜택형에서 상품 카드 최소 폭 때문에 가로 경계가 넘칠 수 있었다.

## 수정

- 4~12종은 밀도별 행 레이아웃으로 전환하고, 가격 요소에 한 줄 계약을 추가했다.
- Playwright 렌더 결과에서 한 줄 가격의 줄바꿈·절삭과 배너 경계 넘침을 수집해 QA 게이트가 실패시키도록 했다.
- 전체 카탈로그에 실제 사진이 있는 것을 확인한 후 SVG 제품 실루엣 대체 출력을 제거했다.
- 3종 혜택형은 `minmax(0, 1fr)` 3열 카드와 세로형 카드 정보 구조로 고정했다.

## 검증

- 종합 7패턴 × 제품 2~12종 = 77개 Playwright 실제 렌더.
- 가격 줄바꿈/절삭 0건, 배너 경계 넘침 0건.
- `npm run build`, `npm run test` 통과.

## 잔여 차단 요소

공식 로고 원본이 프로젝트에 없어 원본 시안과의 100% 픽셀 일치 검수는 `design-qa.md`에서 blocked로 기록했다. 아이스 캠페인은 레퍼런스 기반으로 분리한 동적 얼음 프레임 배경을 적용했다.

## 후속 수정 — 아이스 패턴 노출

얼음 프레임의 고해상도 질감 때문에 결과 PNG가 공통 500KB 상한을 넘겨 RSI/RCI가 QA에서 탈락하고 UI에 숨겨졌다. 배경은 156KB JPEG로 최적화하고, 아이스 패턴에만 1.5MB 결과 PNG 상한을 적용했다. 단품 1종(RSI)과 종합 3종(RCI)은 실제 렌더·QA 통과를 확인했다.
