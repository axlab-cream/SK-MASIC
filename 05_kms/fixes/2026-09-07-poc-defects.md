# PoC 결함 5건 · 원인과 수정

## FIX-01 최소폰트가 항상 16px 로 측정됨
- 증상: 모든 배너가 `min_font 16.0px ≥ 32px` 로 실패
- 원인: `getComputedStyle(slot)` 은 슬롯 컨테이너를 읽는다. 컨테이너는 font-size 를 상속만 하므로 body 기본값 16px 이 나온다
- 수정: 슬롯 안의 **자식 없는 텍스트 리프**를 순회해 최소값을 취한다
- 교훈: 측정 대상은 "스타일을 선언한 요소"가 아니라 "글자가 그려진 요소"다

## FIX-02 SK Red + 흰 글씨가 AA 미달 (4.49:1)
- 증상: `가격 배지 4.49:1 < 4.5` — 800×600 에서만 발생
- 원인: 배지 폰트가 18px(짧은변 600 × 3%)이라 WCAG 큰 글씨 기준(≥18.66px bold)에 0.66px 모자라 본문 기준 4.5:1 적용
- 수정: `smallOnRed()` 로 배지 배경만 `#D9002B`(5.27:1) 로 치환. CTA(45px bold)는 3:1 기준으로 `#EA1738` 유지
- 교훈: 가이드가 Red Deep 을 "작은 글씨 대비 보강"으로 정의해 둔 이유가 바로 이 경계다

## FIX-03 고지문 대비 3.41:1
- 원인: 고지문 색으로 `#8A8A8A`(Gray 500) 사용
- 수정: `#666666`(Gray 600, 5.74:1) 로 상향. 다크 테마도 동일 규칙
- 교훈: Gray 500 은 취소선·비활성 전용 (D-13)

## FIX-04 밴드가 특정 패턴에서만 렌더됨
- 증상: 혜택 강조·아이스 캠페인이 뉴트럴 화이트와 시각적으로 구분되지 않음
- 원인: `if (st.band && slots.band === 'headline')` — `band` 키를 S3 패턴만 선언한다
- 수정: 밴드는 **스타일 속성**이므로 `st.band` 만으로 판단. 높이는 headline 슬롯 하단 + 4.5% 로 계산
- 교훈: 스타일 정체성을 패턴이 결정하게 두면 패턴이 바뀔 때 정체성이 사라진다

## FIX-05 로고 슬롯과 프로모션 태그가 겹침
- 증상: 스타일에 따라 로고 또는 태그 한쪽만 보임
- 원인: 둘 다 `left: sz.left, top: sz.top * 0.4` 로 같은 좌표
- 수정: 태그를 `sz.left + logoW + 1.8%` 로 이동해 같은 줄에 나란히. 밴드 위에서는 색도 전환
- 교훈: 절대 배치 요소는 배타 영역 등록 대상에 포함시켜야 한다 (규칙 2 확장 필요)
