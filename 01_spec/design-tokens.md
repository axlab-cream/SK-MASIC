# 디자인 토큰 — SK magic UI Guide 적용

출처: 제공된 `SKmagic_product_UI_guide.html` (공개 페이지 관찰 기반 **비공식** 역설계 자료).
원칙은 **Neutral first, red with intent**. 넓은 면은 무채색, 레드는 CTA·활성·프로모션에만.

## 컬러

| 토큰 | 값 | 용도 |
|---|---|---|
| red | `#EA1738` | CTA · 활성 · 프로모션. **큰 글씨에만** |
| red-deep | `#D9002B` | **작은 글씨 대비 보강**. 배지 배경 |
| orange | `#FF7A00` | 보조. 제한적 |
| benefit | `#EBFF00` | 쿠폰 · 혜택 한정 |
| ice | `#BFEAFF` | 얼음 캠페인 한정 |
| black / ink | `#151515` / `#222222` | 유틸리티·푸터 / 제목·핵심 텍스트 |
| g700 / g600 | `#4B4B4B` / `#666666` | 보조 제목 / **본문 하한** |
| g500 / g300 | `#8A8A8A` / `#C8C8C8` | 취소선·비활성 / 입력 테두리 |
| line / surface / soft | `#E5E5E5` / `#F6F6F6` / `#FAFAFA` | 구분선 / 제품 이미지 배경 / 페이지 바탕 |
| success | `#0B7A53` | 검수 통과 · 완료 |

### 대비 검증 (실측)

| 조합 | 비율 | 판정 |
|---|---|---|
| `#EA1738` + 흰 글씨 | **4.49 : 1** | 본문(4.5) **미달** · 큰 글씨(3.0) 통과 |
| `#D9002B` + 흰 글씨 | 5.27 : 1 | 통과 |
| `#666666` on 흰색 | 5.74 : 1 | 통과 |
| `#8A8A8A` on 흰색 | **3.41 : 1** | **미달 — 본문 사용 금지** |
| `#EBFF00` + `#151515` | 16.4 : 1 | 통과 |
| `#BFEAFF` + `#222222` | 12.8 : 1 | 통과 |

**결론 2개**
1. SK Red + 흰 글씨는 AA 를 4.49 로 간신히 미달한다. CTA(45px bold)는 큰 글씨 기준 3:1 로 통과하지만
   **배지(18~24px)는 통과하지 못한다** → 배지 배경은 `red-deep` 을 쓴다. (`smallOnRed()` 헬퍼)
2. `#8A8A8A` 는 읽어야 하는 문장에 쓰지 않는다. 취소선 기준가·비활성·18px 이상 큰 글씨에만 허용.

## 타이포

스택 `"Roboto", "Noto Sans KR", Arial, sans-serif` — **Roboto 를 앞에 둬야** 숫자·모델코드는 Roboto,
한글은 Noto Sans KR 로 자동 분기된다. 순서를 바꾸면 숫자 인상이 달라진다.

| 역할 | 데스크톱 | 모바일 | 자간 |
|---|---|---|---|
| 페이지 타이틀 | 56 / 56 · 400 | 28 / 34 | −.05em |
| 섹션 제목 | 32 / 42 · 500 | 20 / 28 | −.045em |
| 상품명 | 18 / 25 · 700 | 16 / 22 | −.035em |
| 본문 | 14 / 22 · 400 | 14 / 22 | −.035em |
| 가격 | 30 / 33 · 700 | 22 / 26 | −.02em · tabular-nums |
| 캡션 · 모델코드 | 13 / 20 | 12 / 19 | 0 (숫자) |

한글에 음수 자간을 주는 것이 이 브랜드의 인상을 만든다. **숫자에는 적용하지 않는다** — 가격 비교 시 자릿수가 흔들린다.

## 레이아웃 · 간격 · 라디우스

- 컨테이너 1200px · 12열 · 거터 16px · 썸네일 350×350 · 섹션 리듬 56px+
- 간격 4px 기반: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96
- 라디우스 **3단계만**: `2` 배지·태그 / `12` 카드·버튼·입력 / `24` 바텀시트. 알약형(999) 사용 금지
- 반응형: `≤767` 좌우 20px · `768–1199` 좌우 32px · `≥1200` 1200px 중앙
- 터치: 주 동작 48px(모바일) / 44px(태블릿) · 찜·비교 아이콘 44×44

## 배너 전용 규칙

- 레드 면적 **한 배너에서 5% 이내**
- 제품 이미지 배경은 흰색 또는 `#F6F6F6`, 제품이 잘리지 않게, **카드 간 스케일 통일**
- 검정 배경에서는 레드 CTA 금지(3:1 미달) → **흰 라인 CTA**
- 고지문 색은 `g600`. `g500`(3.41:1)은 쓰지 않는다
