# 배너 스타일 6종

스타일 1개 = **컬러 테마(고정) × 타이포(고정) × 레이아웃 패턴(제품 수 × 규격으로 자동 결정)**
정의는 `03_engine/layout/styles.mjs`. MC 에게는 완성된 시안만 보이고 styleId·패턴코드는 노출하지 않는다.

| styleId | MC 에게 보이는 이름 | 허용 패턴 | 조건 | 특징 |
|---|---|---|---|---|
| `neutral-white` | 뉴트럴 화이트 | S1 S2 S4 · C2 C3 C4 | 기본값 | 글자·사진 분리. 겹침 구조적 불가 |
| `benefit-yellow` | 혜택 강조 | S2 S3 · C2 C3 C4 C6 | 할인·면제 소재 있을 때 | 검정 밴드 + `#EBFF00` 혜택 칩 3개 |
| `price-focus` | 가격 강조 | S1 S2 · C2 C3 C4 | 약정 혼재 시 자동 제외 | 가격 3단 위계 확대. CTA 는 검정 |
| `premium-black` | 프리미엄 블랙 | S1 S3 S4 · C2 C3 | 월 3만원 이상 권장 | `#151515` + 그라데이션. 흰 플레이트 로고, 흰 라인 CTA |
| `ice-campaign` | 아이스 캠페인 | S2 S3 · C2 C3 | **얼음 제품 대표일 때만** | `#BFEAFF` 밴드 (가이드 지정 용도) |
| `card-list` | 카드 리스트 | C12 C6 | **4종 이상 전용** | 행 리스트. 겹침 원리적 불가 |

## 목록 구성 규칙

| ID | 규칙 |
|---|---|
| L1 | QA 통과한 스타일만 노출. 최소 **3개** 보장 못 하면 규격 격상 재시도 |
| L2 | 정렬 = 해당 MC 의 과거 채택률 내림차순 (`05_kms/success/`) |
| L3 | 시즌 태그가 켜지면 캠페인 스타일을 1순위로 승격 |
| L4 | 가격 표기 스타일은 약정 혼재 시 목록에서 제외 |
| L5 | 선택된 스타일은 **선택한 모든 규격에 동일 적용** — 규격별로 다시 고르게 하지 않는다 |

## 단품 / 종합 차이

- **단품** — 후보 5종 (card-list 제외). 패턴은 규격 종횡비로 결정: 가로 → S1/S4, 정사각 → S2, 세로 → S3(밴드형)/S2
- **종합** — 제품 수로 결정: 2종 C2 · 3종 C3 · 4종 C4 · 5~6종 C6 · 4~12종 C12(카드 리스트)
- 같은 스타일이라도 **규격이 바뀌면 패턴이 바뀐다.** 색·서체는 유지된다
