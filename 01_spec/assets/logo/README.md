# 로고 원본을 여기에 넣는다

배너 좌상단 로고 슬롯은 **이 폴더에 파일이 있으면 자동으로** 이미지로 교체된다.
파일이 없으면 지금처럼 빈 슬롯이 남는다.

## 파일명 규칙

| 파일명 | 쓰이는 곳 |
|---|---|
| `logo.svg` 또는 `logo.png` | 밝은 배경 (뉴트럴 화이트 · 가격 강조 · 혜택 강조) |
| `logo-white.svg` 또는 `logo-white.png` | 어두운 배경 (프리미엄 블랙 · 검정 밴드 위) |
| `logo-black.svg` / `logo-black.png` | `logo.*` 가 없을 때의 대체 |

우선순위는 위 표 순서다. `logo-white` 가 없으면 어두운 배경에도 밝은 배경용 파일을 쓰므로
**검정 배너에서 로고가 안 보일 수 있다** — 어두운 스타일을 쓸 거면 흰색 버전을 함께 넣는다.

SVG 를 권장한다. PNG 를 쓸 경우 슬롯 실제 크기는 짧은 변의 13% × 6.2% 이므로
1080×1350 배너에서 약 **140 × 67px** 이다. 2배수(280×134) 이상으로 준비한다.

## 지켜야 하는 것

- **로고를 그리거나 재현하지 않는다.** 공식 CI 원본 파일만 넣는다 (`DECISIONS.md` D-09)
- 배경이 투명한 원본을 쓴다. 흰 사각형이 붙은 파일은 어두운 배너에서 흰 박스로 보인다
- 비율을 바꾸지 않는다. 슬롯은 `object-fit: contain` 이라 원본 비율을 유지한다
- 고객 발송용 배너는 **공식 CI·BI 확인이 선행**되어야 한다. 이 폴더에 파일을 넣는 것만으로
  대외 사용 승인이 되는 것은 아니다

## 넣은 뒤 확인

```bash
node 03_engine/verify.mjs      # 로고 항목이 OK 로 바뀐다
npm start                      # 3단계 시안에서 좌상단 확인
```

로고 이미지가 깨지면 QA "제품 사진 로드" 항목에서 잡힌다 — 그 배너는 MC 에게 노출되지 않는다.
