# 레이아웃 · 겹침 회피 규칙

슬롯 좌표는 **세이프 영역 기준 0~1 정규화로 한 번만** 정의한다 (`03_engine/layout/patterns.mjs`).
같은 정의가 4규격 전부에 쓰인다.

## 겹침 회피 6개 규칙 (순차 적용)

| # | 규칙 | 구현 |
|---|---|---|
| 1 | **레이어 우선순위 고정** — text(z=3) > badge(z=3) > product(z=2) > bg(z=0). 텍스트가 가려지는 일은 원천 차단 | CSS z-index |
| 2 | **배타 영역 + IoU 재배치** — 텍스트 rect + padding(짧은변 2%)을 배타 영역으로 등록. 제품이 IoU > 0.05 로 침범하면 **축소 ×0.94 + 여유 방향 이동**, 최대 5회 | `resolve()` |
| 3 | **fit-text 이진 탐색** — 박스 안에 들어가는 최대 폰트를 14회 이진 탐색. 하한 미달 시 ① 줄 수 증가 → ② 카피 재생성 → ③ 규격 격상. **절삭(…) 금지** | `fitText()` |
| 4 | **대비 보장 — 밴드 우선, 스크림 차선** — 텍스트는 불투명 밴드 안에 두는 것이 1순위. 그래도 이미지 위에 10% 넘게 남으면 그라데이션 스크림 삽입 | `scrim()` |
| 5 | **제품 이미지 여백 트림** — 원본 CDN 이미지는 투명·흰 배경 여백이 커서 시각 중심이 슬롯과 어긋난다. bbox 트림 후 컨테인 피팅. **겹침 문제의 절반이 여기서 해결된다** | `catalog/trim` |
| 6 | **가격 배지 코너 앵커** — 제품 슬롯 우하단 앵커 + 슬롯 밖 클램프. 배지끼리 겹치면 우하 → 좌하 → 우상 → 좌상 순환 | `.pbadge` |

## QA 게이트 8항목

전부 통과해야 MC 에게 노출한다. 실패는 숨기고 재시도한다.

| 항목 | 기준 | 비고 |
|---|---|---|
| 텍스트 ∩ 제품 IoU | ≤ 0.02 | |
| 텍스트 ∩ 텍스트 겹침 | 0 | 4px² 초과 교집합을 1건으로 센다 |
| 최소 폰트 | ≥ `max(18, 짧은변×3%)` | notice·보조 텍스트 제외 |
| 고지문 · 보조 텍스트 하한 | ≥ `max(14, 짧은변×1.4%)` | 단위 접미사·취소선 기준가 포함 |
| 텍스트 대비비 | 본문 4.5:1 / **큰 글씨 3:1** | ≥24px 또는 ≥18.66px bold = 큰 글씨 |
| 세이프존 침범 | 0 | notice 만 예외 |
| 오버플로 · 절삭 | 0 | fit-text 가 하한 미달로 종료된 슬롯 수 |
| 파일 용량 | ≤ 500KB | 카톡 전송 최적 |
| 필수 고지문 | 약정 · 의무사용 · 등록비 · 위약금 포함 | |

## 판정 근거

**픽셀 추정을 쓰지 않는다.** Playwright 가 `document.fonts.ready` 이후 수집한
`getBoundingClientRect()` 실측값으로만 계산한다. 폰트 로딩 전에 재면 폴백 폰트로 측정된다. (D-16)

## 실패 반송 정책

```
문구 문제(오버플로·최소폰트)  → [5] copy    최대 2회 (상한을 낮춰 재요청)
배치 문제(IoU·세이프존·대비)  → [7] compose 최대 5회
둘 다 실패                    → 규격 격상 후 재시도
그래도 실패                    → 목록에서 제외 (MC 에게 보이지 않음)
후보가 3개 미만               → 규격 격상해 다시 채운다
```
