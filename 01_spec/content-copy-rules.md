# 콘텐츠 · 카피 규칙

가이드의 **“제품소개는 차이가 먼저 보이게”** 원칙을 문구 생성 단계의 실제 제약으로 옮긴 문서.

## 최우선 규칙 — 속성 3개, 같은 순서로

한 문장에 모든 장점을 넣으면 비교가 안 된다. **관리 방식 → 핵심 기능 → 색상** 순서를 모든 제품에 반복한다.

```
✗ 혁신적인 기술과 아름다운 디자인을 갖춘 최고의 프리미엄 정수기
✓ 방문관리 · 냉온정얼음 · 오트밀 베이지
```

## 제품명 조립

`라인명 + 핵심 유형 + 크기 변형` → `MEGA ICE 얼음정수기 mini`
불필요한 수식어는 뺀다. 모델코드는 제품명 옆이 아니라 **상단 별도 줄**에 Roboto 로.

| 탐지 | 치환 | 분류 |
|---|---|---|
| 최고 · 최상 · 1위 | 에너지소비효율 1등급 | 최상급 |
| 완벽한 · 무조건 | (삭제) | 검증 불가 |

## 가격 표기 필수 조건

1. 기준가는 **취소선 + Gray 500**, 할인가·계약기간·제휴카드 조건을 **시각적으로 분리**
2. 고지문에 **약정기간 · 의무사용기간 · 등록비 · 중도해지 위약금** 4항목 포함
3. 할인 조건을 **색상 외 텍스트로** 설명 (가이드 접근성 점검항목)
4. 약정 기간이 다른 제품이 섞이면 **가격 전체를 숨기고** “상담 시 안내”로 대체
5. 카탈로그가 **7일 초과**면 배너 생성 자체를 차단

## 안내 문구 어조

“실패했습니다” 같은 시스템 말투를 쓰지 않는다. **결과 먼저, 이유 다음.**

```
✓ “최고의 프리미엄”은 광고에 쓸 수 없어서 “방문관리 · 냉온정얼음 · 1등급”으로 바꿨습니다
✓ 이 배너는 보관함에 자동 저장됩니다. 나중에 다시 받거나 그대로 재사용할 수 있어요
✗ 컴플라이언스 검증 실패 (code: BANNED_SUPERLATIVE)
```

## 배너의 접근성

배너는 PNG 라 스크린리더가 읽을 수 없다. 그래서 다운로드 시
**동반 인사말에 핵심 정보(제품·가격·조건)를 텍스트로 반복**해 넣는다.
이미지를 못 보는 고객도 문자만으로 판단할 수 있어야 한다.
